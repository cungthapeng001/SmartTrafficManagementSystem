# Smart Traffic Management System

A C++ Data Structures project simulating traffic flow at a road intersection using Queues.

## Phase 1 Features
- Register vehicles
- Queue-based traffic management (FIFO)
- Traffic density calculation
- Traffic signal timing based on density

## Building the Project

### Prerequisites
- CMake (version 3.10+)
- A C++ Compiler (e.g., GCC, Clang, MSVC)

### Build Instructions
```bash
mkdir build
cd build
cmake ..
cmake --build .
```

### Running the Application
```bash
# On Windows
Debug\traffic_app.exe
# Or depending on generator:
./traffic_app.exe
```

### Running Tests
```bash
# On Windows
Debug\traffic_test.exe
# Or depending on generator:
./traffic_test.exe
```
