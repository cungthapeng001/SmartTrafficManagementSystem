# Smart Traffic Management System

## Project Overview
The Smart Traffic Management System is a university-level C++ console application designed to simulate and manage traffic flow at a single intersection. It applies fundamental Data Structures and Algorithms (DSA) to optimize vehicle wait times and prioritize emergency vehicles.

## Build Instructions
This project uses CMake.

To build:
```bash
mkdir build
cd build
cmake ..
cmake --build .
```

To run:
```bash
./SmartTrafficManagementSystem
```
